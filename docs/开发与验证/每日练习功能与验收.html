已经落实的业务约束

规则实现
统一每日题学习方向 + 用户本地日期唯一；首次领取时从已发布候选版本确定并保存，之后所有同方向同日期用户读取相同版本。方向与领域分别建模。
用户身份服务端从会话 Cookie 确定用户；接口拒绝额外传入 user_id。作答结果查询只允许本人读取。
答案与版本提交前只返回题干、选项和来源，答案与解析仅在本人提交后返回。每日题引用固定发布版本，发布新版不会修改旧作答依据。
提交事务同一 MySQL 事务写入作答、规则分数、提交日打卡与复习计划。发生异常整体回滚；每日题每个用户只允许首次正式提交。
幂等与并发用户 + UUID 幂等键唯一；同键同内容重试返回原结果，同键不同内容返回 409；用户 + 每日题唯一。通过用户行锁串行化同一用户的提交，不锁住其他用户。
跨天按后端时间和用户时区计算日期，默认 Asia/Singapore。尚未提交的旧日期题目在跨天后返回 409，提示加载今天的题；已经成功的提交即使次日重试仍返回原结果，不改变打卡日期。
复习答错次日；连续答对按 1、3、7、14 天递增并封顶。每个 Attempt 保存规则版本、间隔、依据和当时到期日，ReviewPlan 维护当前状态。客观题首版不要求自评，尚未开放自评输入。

一次成功提交即可形成当天打卡，同一天完成两个方向也只保留一条用户/日期打卡。复习日期已经落库，但本轮没有实现到期复习页面和历史列表；可在每日练习中刷新恢复当天结果。

接口与数据流

接口作用
POST /api/v1/auth/register、/login创建账号或验证密码并设置会话；需要 X-Requested-With: learning-platform。
GET /api/v1/auth/me恢复当前账号、时区与 CSRF 令牌。
POST /api/v1/auth/logout撤销会话并清除 Cookie。
GET /api/v1/tracks?domain_code=computer读取领域内学习方向。
GET /api/v1/today?track_id=...认证后获取固定每日题；本人已完成时附带原结果，无已发布题时 assignment 为 null。
POST /api/v1/attempts提交 daily_assignment_id、question_version_id、answer、idempotency_key；由服务端判分，不接受客户端分数。
GET /api/v1/attempts/{id}读取本人的固定版本结果；非本人或不存在统一返回 404。

新表：users、auth_sessions、tracks、questions、question_versions、daily_assignments、attempts、check_ins、review_plans。均使用 InnoDB / utf8mb4、外键和相应唯一约束。数据库时间统一保存 UTC，打卡与复习使用单独的本地日期字段。

登录与浏览器请求保护
  • 密码通过随机盐的 scrypt 保存；数据库仅保存随机会话令牌的 SHA-256 摘要，令牌有效期 7 天。
  • Cookie 使用 HttpOnly、SameSite=Strict 和 /api 路径。认证后的写请求需要与会话绑定的 X-CSRF-Token，注册/登录使用自定义请求头且不开放跨域。
  • 接口响应禁止缓存；认证校验错误不回显请求原文和密码；数据库错误只返回通用 503。
  • 前端不在 localStorage 保存密码或会话令牌。提交结果不确定时保留原答案和幂等键，重试不会生成第二条作答。

本轮本地 MySQL 测试共 16 项通过：包含空库迁移升级/回退、重复导入、密码认证、CSRF、会话过期、答对/答错、答案不提前泄露、用户隔离、非法载荷、同键与异键并发提交、事务故障回滚、跨午夜重试、版本冻结、无题方向与复习规则。

浏览器验收使用独立本地演示账号，不使用个人学习数据；确认选择选项、提交后显示解析、打卡和下次复习日期，以及刷新恢复结果。凭据与截图仅放在被忽略的 build/verification/，不得提交。测试客户端仍有既有 Starlette/httpx 弃用提示，不影响本轮断言。

测试库必须显式指定为以 _test 结尾的空专用 MySQL 库；测试只清理本次创建的表。不以 SQLite 代替 MySQL 的并发和事务证据。已有 CI 会运行完整 pytest；远程结果与分支交付状态以对应 PR 为准。

范围与后续工作

  • 首版仅支持单选题；尚无简答题 AI 评分、自评输入、题库管理页面和人工复核。发布入口当前为后端样题导入命令。
  • 每道样题当前归属一个方向，尚无跨方向题目映射；选题采用确定性轮转，不是个性化推荐。用户时区默认新加坡，尚无设置页面。
  • 同日每日题不提供改答案或再答；后续复习应创建新的 Attempt，不能覆盖旧记录。
  • 本地登录能力尚未包括密码找回、账号管理、登录限流与审计。上线前需补齐这些能力，并启用 HTTPS、COOKIE_SECURE=true；当前没有部署和 CD。
  • 复习和历史列表尚未开放，离线行为分析尚未接入。规则效果须通过后续实验检验。

实现参考：Python scrypt、SQLAlchemy 事务、FastAPI Cookie 响应。
