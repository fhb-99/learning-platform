# 个性化知识练习与复习系统

基于学习行为分析的毕业设计，主要研究学习行为分析与可解释复习策略。

核心技术栈：Vue 3 + TypeScript、Python FastAPI、MySQL、DuckDB + Parquet。当前处于设计与仓库初始化阶段，尚无可运行的业务系统。

## 首个开发目标

发布客观题 → 选择方向并领取每日题 → 作答与判分 → 提交日打卡 → 生成个人复习安排。

同方向、同一本地日期使用统一每日题；个人完成状态与复习队列分别记录。起始复习规则采用 1、3、7、14 天递增间隔，效果仍待实验验证。

## Git 工作方式

本项目使用独立仓库，默认分支为 `main`，暂不设长期 `develop`。后续改动从最新 `origin/main` 建立 `feat/*`、`fix/*` 或 `chore/*` 分支，通过 PR 合入。

主分支保护目标：要求 PR、禁止强推和删除、管理员同样受约束、合并前解决所有讨论。单人开发阶段不强制他人审批；业务 CI 建立并成功运行后再配置必需状态检查。初始化首次提交用于建立主分支，后续普通开发不直接推送 `main`。

运行配置、凭据、依赖、日志和实验产物不进入 Git；临时文件留在项目内已忽略的 `build/` 或 `out/`。
